# 부산 영화축제 탐험대

초등학교 4학년 영화교육 1차시(40분). 부산국제영화제(BIFF), 부산국제어린이청소년영화제(BIKY), 부산국제단편영화제(BISFF)를 조사하고 비교합니다.

## 40분 수업 흐름

| 시간 | 활동 | 웹앱에서 할 일 |
|---|---|---|
| 5분 | 부산의 영화축제 떠올리기 | 첫 화면에서 영화제와 영화관의 차이 이야기하기 |
| 15분 | 축제 자료 조사 | 축제 카드 선택 → 자료 읽기 → 중요한 근거 담기 |
| 15분 | 비교·정리 | 닮은 점과 다른 점 기록 → 한 축제 선택 → 자기 말로 조사 카드 작성 |
| 5분 | 공유 | 자료 근거와 내 생각을 연결해 발표 → PNG 저장 |

세 영화제의 모든 자료를 읽을 필요는 없습니다. 한 축제를 깊이 조사한 뒤 다른 축제와 비교해도 됩니다. 조사를 마친 학생은 ‘부산에 주는 도움’을 자료 근거와 연결해 씁니다. 이 부분은 공식 자료의 결론을 옮기는 것이 아니라 학생 자신의 추론입니다. 카드에는 축제 장소·활동·특징·생각·자료 근거와 선택한 비교 기록이 담깁니다.

## GitHub + Vercel 배포

1. ZIP 압축을 풉니다. `index.html`, `app.js`, `style.css`, `data.js`, `assets` 폴더가 함께 있는지 확인합니다.
2. 새 GitHub 저장소를 만들고 이 파일들과 `assets` 폴더 전체를 업로드합니다. GitHub의 **Add file → Upload files**를 사용하면 됩니다. ZIP 파일 자체를 올리는 방식은 아닙니다.
3. Vercel에서 **Add New → Project → Import Git Repository**로 해당 저장소를 선택합니다.
4. Framework Preset은 **Other**, Root Directory는 **index.html이 있는 폴더**로 설정합니다. 앱 파일들을 저장소 맨 위에 올렸다면 기본값 `.`을 씁니다.
5. Build Command와 Install Command는 비워 두고, Output Directory는 기본값을 사용하거나 `.`으로 지정한 뒤 Deploy합니다. 빌드가 필요 없는 정적 웹앱입니다.
6. 배포된 HTTPS 주소를 학생들에게 나눠 줍니다. 환경 변수, Firebase, API 키는 필요 없습니다.

두 앱은 별도의 저장소·Vercel 프로젝트로 배포하면 각각의 학생 링크가 생깁니다. 한 저장소에서 운영하고 싶다면 두 폴더를 나란히 올리고 `/01-festival/`, `/02-locations/` 경로로 접근할 수도 있습니다.

## 학생 결과 모으기

- 학생 또는 모둠 대표 기기에서 활동합니다. 1~6모둠을 선택할 수 있으며 개인 활동도 가능합니다.
- 결과는 A4 세로 비율 1485 × 2100픽셀 PNG로 저장합니다. 인쇄/PDF 버튼은 브라우저 인쇄 창을 엽니다. 용지는 A4 세로, 배율은 페이지에 맞춤으로 설정합니다.
- PNG를 선생님의 기존 패들렛 등에 올리면 됩니다. 자동 제출이나 학급 실시간 동기화 기능은 없습니다.
- 발표 화면은 카드가 크게 보이며, 닫기 버튼은 아래쪽에 있습니다.
- 여러 학생이 태블릿을 돌려 쓸 때에는 **내 기록 관리 → 기록 파일 백업** 또는 카드 저장 후 새 활동을 시작합니다.

## 기록과 사진

- 입력 내용은 이 기기·이 브라우저의 localStorage에 자동 저장됩니다. 새로고침 후 이어 쓸 수 있습니다.
- 다른 기기로 자동 전송되지는 않습니다. 다른 기기에서는 **내 기록 관리 → 기록 파일 불러오기**로 이어 씁니다.
- 사진은 서버로 업로드하지 않고 브라우저에서만 처리합니다. JPG·PNG·WebP, 15MB 이하 사진을 넣을 수 있으며, 긴 변을 줄여 저장합니다.
- 브라우저 데이터 삭제나 시크릿 창 종료 시 기록이 지워질 수 있으므로 결과물 또는 기록 파일을 저장합니다.
- 같은 도메인의 두 앱도 저장 키가 달라 기록이 섞이지 않습니다.

## 파일 구성과 수정

- `index.html`: 앱 구조
- `style.css`: PC·태블릿·작은 화면 레이아웃과 인쇄 스타일
- `data.js`: 조사 자료, 출처, 낱말 설명, 수업 시간표
- `app.js`: 활동 진행, 자동 저장, 사진 처리, PNG 만들기
- `assets/`: 실제 사진과 부산 영화 마을 일러스트
- `SOURCES.md`: 자료·사진 출처
- `vercel.json`: 정적 배포용 응답 헤더

외부 JavaScript 라이브러리나 폰트를 불러오지 않습니다. 조사 글과 그림, 카드 만들기는 배포된 앱 안에서 이루어지고 원문 링크를 누를 때만 외부 사이트로 이동합니다. 이미지는 배포용 파일에 함께 들어 있습니다. 현재 버전은 서비스 워커를 사용하지 않아 업데이트 후 이전 앱이 남는 문제를 줄였습니다. 완전한 오프라인 앱으로 설치되는 방식은 아닙니다.

## 실행·검증

배포 전 PC에서 확인하려면 이 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000/`을 엽니다. 브라우저별 파일 보안 차이가 있으므로 `file://`로 직접 열기보다 HTTP/HTTPS로 실행합니다.

검증: 자료 열기와 수집, 글 입력, 카드 미리보기, 1485 × 2100 PNG 저장, 새로고침 후 기록 유지, 1024px 태블릿 및 390px 화면에서 가로 넘침 확인. 기본 자료는 2026년 사례이며, 다음 해 수업에서는 `data.js`의 행사 연도·장소·원문 링크를 다시 확인합니다.
